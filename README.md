# Advent Your Year

Photo advent calendars at **josephjackman.com/adventyouryear**. People make an account, pick an illustrated
calendar design, put a photo and a note behind each of 24 doors, and send a link. Recipients make an account,
the calendar is saved to it, and each door unlocks on its date in the month the creator picked.

## How it works

- **Accounts:** sign up with email + password, confirm with a 6-digit code, reset a forgotten password with a code.
- **Many calendars per account.** Each calendar has its own design, month, title, 24 photos and notes.
- **Sharing is per calendar, by email.** Add the email addresses a calendar is for. Only people signed in with one
  of those (verified) emails can open it, and it appears in their account automatically. Removing an email removes
  access. The share link just takes them to it; on its own it grants nothing.
- **Day locking is enforced by the database:** a recipient's browser never receives a photo or note until that day
  arrives in the calendar's time zone, so there's no peeking.

## How it's built

- **Static site** (plain HTML/CSS/JS) in `docs/`, served by GitHub Pages at josephjackman.com/adventyouryear.
  Routing uses `#hash` links, so no server rewrite rules are needed.
- **Supabase** (free tier) for accounts, email codes, the database and private photo storage.
- **Email** goes through Resend from the same josephjackman.com sender as Roleplay20: Supabase uses it for codes,
  and the `send-invite` Edge Function uses it for "Email the invitation".
- Without Supabase settings the app runs in **preview mode**: everything is stored in the browser and email
  codes appear on screen.

## Project layout

| Path | What it is |
| --- | --- |
| `src/designs/parlor.js` | Design 1, "Christmas Eve Parlor": the illustrated scene (drawn as SVG) and its animated effects |
| `src/layouts.js` | Door positions per design (generated by `tools/layout.mjs`) |
| `src/board.js` | The calendar: doors, 3D flaps, fire/lights/snow animation, the photo view |
| `src/app.js` | Pages: landing, sign in/up, email code, reset password, dashboard, editor, share, calendar |
| `src/api-supabase.js` / `src/api-demo.js` | Live backend / browser-only preview backend (same interface) |
| `supabase/migrations/` | Tables, sharing + day-lock rules, share-link functions, photo bucket |
| `supabase/config.toml` | Auth settings: 6-digit codes, email templates, Resend SMTP |
| `supabase/functions/send-invite` | Emails a calendar invitation to the people on its list |
| `tools/supabase-setup.mjs` | One-shot backend setup |
| `build.mjs` | Builds `docs/` (the live site) and `preview/` (single-file preview) |

## Going live / updating

First time (or to repair settings), from this folder:

```
npm install
npx supabase login
node tools/supabase-setup.mjs
```

The setup script creates or reuses the `adventyouryear` Supabase project, loads `supabase/migrations`, pushes the
auth settings in `supabase/config.toml` (codes, templates, Resend SMTP read from Roleplay20's `.env` without printing
it), deploys `supabase/functions/send-invite`, and writes `docs/config.js`.

After code changes: `node build.mjs`, commit, push. GitHub Pages serves `docs/` from `main`.

Schema changes: add a new file in `supabase/migrations/`, then `npx supabase db push` (database password is in
Windows Credential Manager as "AdventYourYear-supabase-db").

## Local preview

```
node tools/serve.mjs 5173
```
Then open http://localhost:5173/docs/ (preview mode until `docs/config.js` is filled in).

## Adding the other 19 designs

Each design is one file in `src/designs/` exporting `build()` (returns the SVG scene plus light/candle positions),
a `title` path for the banner text, and an `effects` list. Generate its door layout with
`node tools/layout.mjs <name> <seed>` after adding its keep-out zones to `tools/layout.mjs`, and add the file to
`JS_ORDER` in `build.mjs`. The design picker lights it up automatically.
